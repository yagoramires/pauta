# Radar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de barra de menu com dois ícones: 📋 Jira (meus cards + livres da sprint ativa, trocar status, pegar card) e 💬 Slack (DMs e menções não lidas, notificação com o Slack fechado).

**Architecture:** SwiftPM executável, AppKit `NSStatusItem` ×2 + `NSPopover` com SwiftUI, igual ao Dose (`~/Documents/dose`). Clientes HTTP finos com `URLSession` async, lógica pura (filtros, agrupamento, contagens) separada dos clientes pra ser testada no `--selftest`. Um `Poller` atualiza os dois a cada 120 s.

**Tech Stack:** Swift 6 toolchain em language mode v5, macOS 14+, só CommandLineTools (sem Xcode, sem XCTest), Jira Cloud REST v3 + Agile 1.0, Slack Web API (user token).

**Spec:** `docs/superpowers/specs/2026-10-23-radar-design.md`

## Global Constraints

- Pasta `~/Documents/radar`, bundle id `local.radar`, nome "Radar", `LSUIElement` true, `CFBundleDevelopmentRegion` pt-BR. Textos da UI em pt-BR.
- Build com `scripts/build.sh [--run]` copiado do Dose, assinando com "Aero Local Signing".
- `@State` não compila só com CLT: usar `@ViewState` (copiar de `dose/Sources/Dose/Views/Root.swift:134`). Nada de `@Entry`.
- Credenciais em `~/Library/Application Support/Radar/credentials.json`, 0600, diretório 0700, escrita atômica (copiar o `save()` do `hub/Sources/Hub/Credentials.swift`). **Nunca o Keychain. Nunca logar token.**
- Log em `~/Library/Logs/Radar/radar.log` (copiar `dose/Sources/Dose/Log.swift`).
- Só APIs oficiais. Slack só com user token `xoxp-`, nunca token de sessão ou cookies do navegador.
- Atualização a cada 120 s, ao abrir um popover e ao acordar o Mac.
- Projeto Jira padrão `ACME`.
- Git só local (`git init`). Não criar repo no GitHub nem dar push.
- Testes = asserts `precondition` no `Radar --selftest`, que imprime `selftest ok` (padrão do Deck: `deck/Sources/Deck/main.swift:22`).

## Review Focus

1. **Clique duplo / clique enquanto atualiza** em "Pegar" ou numa transição: tem que fazer uma requisição só (botão desabilitado enquanto `busy`) e conferir antes que o card continua sem responsável. Teste: `freeStillFree` no Task 3.
2. **Primeira execução com 40 DMs antigas não lidas:** não pode soltar 40 notificações. Na primeira rodada, tudo vai pro `notified` sem notificar. Teste: `notifierFirstRunIsSilent` no Task 5.
3. **Token expirado ou revogado no meio do dia** (401 do Jira, `invalid_auth` / `token_revoked` do Slack): o popover mostra "Token inválido · abrir ajustes", o ícone fica com `exclamationmark`, e a lista antiga continua visível marcada como desatualizada. Nada de travar ou ficar em branco. Teste: `apiErrorMapping` no Task 2 e no Task 4.
4. **429 do Slack:** respeitar `Retry-After` e pular a rodada, sem martelar. Teste: `retryAfterParsed` no Task 4.
5. **Comparação de `ts` do Slack:** `"1712345678.000100"` contra `"1712345678.1"`. Comparar como string ou Double dá erro. Teste: `tsOrdering` no Task 4.

### Task 4: Cliente e lógica do Slack

**Files:**
- Create: `Sources/Radar/Slack/SlackModel.swift`, `Sources/Radar/Slack/SlackClient.swift`
- Modify: `SelfTest.swift`, `main.swift` (`--dump slack`)

**Interfaces:**
- Consumes: `HTTP`, `APIError`, `Credentials`.
- Produces:
  - `struct SlackTS: Comparable, Hashable, Codable { let raw: String; init(_ raw: String) }`. Compara por (segundos `Int`, micros `Int` com a fração completada à direita até 6 dígitos). `var date: Date`.
  - `struct SlackItem: Equatable, Identifiable { let channel: String; let ts: SlackTS; let threadTs: SlackTS?; let userId: String; var userName: String; let text: String; let isDM: Bool; var channelName: String?; let permalink: URL?; var id: String { "\(channel):\(ts.raw)" } }`
  - `struct Seen: Codable { var ids: Set<String> }` persistido em `Application Support/Radar/slack-state.json`, junto com `notified`.
  - `func unreadItems(_ candidates: [SlackItem], lastRead: [String: SlackTS], me: String, seen: Set<String>) -> [SlackItem]`: mantém o que é de outra pessoa, que não está em `seen` e cujo `ts > lastRead[channel]`. Sem `lastRead`, mantém. Ordena do mais novo pro mais antigo.
  - `func slackError(_ json: [String: Any]) -> APIError?`: `ok:false` com `invalid_auth`/`token_revoked`/`not_authed`/`account_inactive` → `.unauthorized`, `ratelimited` → `.rateLimited(30)`, outro → `.server(error)`.
  - `final class SlackClient { init(token: String); func authTest() async throws -> (userId: String, teamId: String, teamURL: URL); func ims() async throws -> [(id: String, userId: String?, isMPIM: Bool)]; func info(_ channel: String) async throws -> (lastRead: SlackTS?, latest: SlackTS?, name: String?); func history(_ channel: String, after: SlackTS) async throws -> [SlackItem]; func mentions(of userId: String) async throws -> [SlackItem]; func userName(_ id: String) async throws -> String }`. `userName` tem cache em memória.

Estratégia de busca (decisão do plano, dentro dos rate limits):
- Menções: `search.messages` com `query: "<@ME>"`, `sort: timestamp`, `count: 50`. Pega canal, `ts`, `thread_ts` (extraído do `permalink`) e `permalink`. Para cada canal distinto, faz `info` (com cache de 60 s) e pega o `last_read`. Entram menções em thread.
- DMs: `users.conversations types=im,mpim` (paginado, com cache de 10 min). A cada rodada, chama `info` em no máximo 40 DMs: primeiro as com `latest` mais recente conhecido, e o resto em rodízio. Se `latest > lastRead`, chama `history(after: lastRead)`. Comentário `shortcut:` dizendo que respostas em thread de DM sem menção não são rastreadas no v1, a não ser que a thread apareça no history. Se o usuário sentir falta, usar `conversations.replies` nas threads com `latest_reply > last_read`.
- Mensagens com `subtype` (join, bot_message de sistema) ficam de fora.
- `.rateLimited` interrompe a rodada. A próxima só roda depois de `retryAfter`.

- [ ] **Step 1: testes falhando:**
  - `tsOrdering`: `SlackTS("1712345678.000100") < SlackTS("1712345678.1")`, `SlackTS("1712345679.000001") > SlackTS("1712345678.999999")`, e dois `ts` iguais com escrita diferente (`"…​.1"` e `"…​.100000"`) dão `==`.
  - `unreadFilter`: itens de `me` saem, os que estão em `seen` saem, `ts <= lastRead` sai, sem `lastRead` fica, e a ordem é decrescente.
  - `slackErrorMapping`: `["ok": false, "error": "token_revoked"]` → `.unauthorized`, `"ratelimited"` → `.rateLimited(retryAfter: 30)`, `["ok": true]` → nil.
  - `retryAfterParsed`: `HTTP.error(status: 429, headers: ["Retry-After": "7"], …) == .rateLimited(retryAfter: 7)`.
  - `threadFromPermalink`: `https://x.slack.com/archives/C1/p1712345678000100?thread_ts=1712345600.000200&cid=C1` → `threadTs == SlackTS("1712345600.000200")`.
  Run `--selftest` → FAIL.
- [ ] **Step 2:** Implementar `SlackModel.swift`.
- [ ] **Step 3:** `--selftest` → ok.
- [ ] **Step 4:** Implementar `SlackClient` (POST form-encoded com `Authorization: Bearer`, conferindo `ok` via `slackError`). `Radar --dump slack` imprime quantas DMs, quantas menções e as não lidas (canal, autor, 40 primeiros caracteres), sem tokens. Conferir com o Slack de verdade, com uma DM não lida que ele mesmo peça pra alguém mandar.
- [ ] **Step 5:** Commit `feat: cliente e regras do Slack`.
